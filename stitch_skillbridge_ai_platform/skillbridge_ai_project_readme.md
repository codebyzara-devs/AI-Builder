# SkillBridge AI – Project Documentation

## Overview
SkillBridge AI is a premium SaaS application designed to bridge the gap between academic learning and career readiness. It uses AI to analyze skills, review resumes, and provide personalized learning roadmaps for students and professionals.

## Core Features
- **AI Skill Analysis**: Detects gaps in your skillset based on career goals.
- **Resume Review**: Instant AI-powered feedback on resume quality and content.
- **Learning Roadmaps**: Interactive, step-by-step paths to becoming "Internship Ready."
- **AI Career Coach**: A 24/7 chat interface for career advice and interview prep.
- **Analytics Dashboard**: Visual tracking of skill growth and job readiness.

## User Journey
1. **Onboarding**: Splash Screen → Landing Page → Sign Up.
2. **Setup**: Email Verification → Detailed Profile Setup (Goals, University, Skills).
3. **Daily Growth**: Dashboard → AI Coaching → Skill Management → Roadmap Progress.
4. **Optimization**: Resume Upload → AI Analysis → Targeted Learning.
5. **Monitoring**: Analytics tracking and Profile management.

## Visual Identity
- **Primary Color**: #2563EB (SkillBridge Blue)
- **Aesthetic**: Minimalist, high-contrast, professional SaaS.
- **Typography**: Inter (Modern Sans-serif)
- **Components**: Shadowed cards, rounded buttons (8px), and Lucide-style iconography.
