# 🚀 SkillBridge AI

> An AI-powered career guidance and skill development platform that helps students identify their strengths, improve their resumes, receive personalised career recommendations, and prepare for internships and jobs.

---

# 📌 Problem Statement

Many students struggle to decide their career path because they lack personalised guidance, resume feedback, interview preparation, and information about the skills required in today's job market.

Traditional career counselling is expensive, time-consuming, and not easily accessible to everyone.

---

# 💡 Solution

SkillBridge AI provides an intelligent career guidance platform that uses Artificial Intelligence to analyse a student's profile and recommend:

- Career paths
- Required skills
- Resume improvements
- Interview preparation
- Learning resources
- Internship guidance

The platform makes career counselling accessible, fast, and personalised.

---

# 🎯 Target Users

- University Students
- Fresh Graduates
- Internship Applicants
- Job Seekers
- Career Changers

# ⚙️ Installation

Clone the repository

```bash
git clone https://github.com/codebyzara-devs/SkillBridge-AI.git
```

Go to the project folder

```bash
cd SkillBridge-AI
```

Install dependencies

```bash
npm install
```

Run the development server

```bash
npm run dev
```

Open

```
http://localhost:5173
```

---

# 📦 Build
